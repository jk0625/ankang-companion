# 安康陪伴 · 慢病居家健康陪伴 AI Agent

面向中老年高血压 / 糖尿病患者的居家健康智能体。2026 全国人工智能应用创新大赛 · 广西师范大学校赛参赛作品。

> 它不诊断、不开处方，只做一件事：把散落的血压血糖、吃不准的医嘱、容易忘的药，用一句话管起来。

---

## 这个作品要解决什么

我国高血压患者超过 2.4 亿、糖尿病患者超过 1.4 亿，其中大量中老年人长期居家自我管理。他们真正面对的不是"没有数据"，而是三件很具体的事：

- **量完了记不住** —— 记在纸上、手机上，或者干脆不记
- **医生的话听不懂** —— "每日一次餐后服用"到底是几点
- **药吃着吃着就忘了** —— 吃没吃记不清，漏了也没人知道

市面上多数健康 App 只做到了记录，本质仍是工具软件：不会思考、不会规划、更不会主动找人。

## 四项真正的 Agent 能力

| 能力 | 实现 |
|---|---|
| **自主规划** | 一句模糊需求 → 结构化任务序列（JSON），不是一次性生成一段话 |
| **工具调用** | 9 个真实工具读写 SQLite：体征查询、趋势分析、用药计划、依从性、医嘱解析、知识检索、报告生成、提醒创建、数据录入 |
| **知识检索** | 325 条慢病条目，BM25 + 口语同义映射 + 病种/心理分类过滤，每条标注出处 |
| **记忆对话** | 记住病种、服药时间、口味偏好、历史趋势，回答带称呼、带追问 |

## 三个差异化设计

### 1. 它认得情绪，不只是认得指标

老年慢病患者最难的往往不是数值，是心里那道坎。系统识别七类情绪（放弃、负担、焦虑、倦怠、自责、孤独、委屈），**先接住情绪，再谈正事**。

> 用户：我不想治了，治不好还花钱
>
> 系统：这话我听着心里也不是滋味。慢慢来，不着急。……这种感觉叫"治疗倦怠"，长期吃药、天天扎手指，谁都会烦。但要分清两件事：病没法根治，不等于管不好。

知识库里专门写了 42 条心理条目。当用户说出"活着没意思"，系统立刻切到危机回应：先接住，再给具体动作，不谈指标、不讲道理。

### 2. 提醒会自己找人，也会自己记账

到点 → 弹窗 + 30 秒轻音乐 + 语音播报药名 + 浏览器通知。点"吃了"或回一句"吃了"即记为已服；30 秒无回应自动判漏服，并提示"要是其实吃了，跟我说一声就改回来"。

同一时间点的多种药**合并成一次提醒、一次确认**，不会连弹两次。

"吃了"如何定位到哪一顿？四级判定：事件 ID → 药名+时间 → 只说时间 → 活跃提醒 / 漏服优先。这一条是踩过坑之后改出来的——详见 [项目文档](docs/)。

### 3. 拍照就能录数据，不联网也能跑

拍一张血压计或血糖仪照片，自动读屏取数。液晶屏的 `9` 容易被认成 `6`，系统加了七段笔段校验纠正。

## 安全与合规

- **不诊断、不开处方**：定位是健康管理辅助
- 危急症状（胸痛、呼吸困难、一侧无力等）→ 立即提示拨打 120，不进入生成环节
- 要求停药、减量、加量 → 直接拒绝，转交医生
- 说出自杀念头 → 切危机模式，给心理援助热线 12356
- 询问家人病情 → 明确说明只管本人数据
- 所有健康建议必须标注知识库出处，检索不到就明说"没有依据"

**知识库内容改写自公开的高血压 / 糖尿病防治指南与科普资料，正式上线前须由执业医师逐条复核。**
